# Henle Path

A local-first, child-friendly learning prototype based on the progression in Henle *First Year Latin*, Lessons 1-2.

## Open it

Run a small local web server in this folder and open `http://127.0.0.1:5177` in a browser.

For example:

```powershell
python -m http.server 5177 --bind 127.0.0.1
```

No account, database, package install, or internet connection is required. Learner progress is saved in the browser on this device.

## Included in this prototype

- Selectable Lesson 1 and Lesson 2 paths
- Six complete quests covering Unit 1, Lesson 1
- Six short quests covering Unit 1, Lesson 2
- Complete Lesson 1 vocabulary, three 20-card word-form rounds, grammar-map, endings, sentence building, accusative, and genitive practice
- XP, hearts, streak, daily goal, and sequential unlocking
- Personal learner name and practice pace
- Personalized Latin sentences using the learner's name
- Timed vocabulary, word-form, and grammar-ending Pairs Challenges
- Review cards and a family progress view
- Responsive desktop and mobile layouts

The curriculum text is newly written for the app and uses short Latin forms and phrases from the lesson rather than reproducing the book.
